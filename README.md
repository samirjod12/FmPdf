## 👻 A little about FmPDF...

**FmPDF** is a lightweight and fast tool for working with PDF files. It focuses on simplicity, speed and a clean experience: open a document, do what you need, and get on with your day.

## ✨ Features

| Feature | Description |
| ------- | ----------- |
| 📖 **Viewer** | Smooth rendering, zoom, page navigation and full-text search |
| 🧩 **Merge & Split** | Combine many PDFs into one or extract any page range |
| 🔄 **Rotate & Reorder** | Fix upside-down scans and shuffle pages with ease |
| 🖼 **Convert** | Export pages to images or extract text |
| 🔐 **Protect** | Add or remove passwords, apply watermarks |
| ⚡ **Fast** | Handles large documents without breaking a sweat |

## 🚀 Installation

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/FmPDF.git
cd FmPDF

# Install dependencies
pip install -r requirements.txt

# Run
python main.py
```

## 🛠 Usage

```bash
# Merge files
fmpdf merge a.pdf b.pdf -o merged.pdf

# Split pages 1-5
fmpdf split input.pdf --pages 1-5 -o part.pdf

# Rotate all pages 90°
fmpdf rotate input.pdf --angle 90 -o rotated.pdf
```

> 🚧 Adjust the commands above to match your real CLI/UI.
